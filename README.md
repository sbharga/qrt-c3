# qrt

Solutions to a set of optimisation / puzzle problems. Each folder is self-contained, with the problem statement in its `README.md` and the submission in `solution.py`.

| Problem | Folder |
| --- | --- |
| Word Search Generation | [`word-search-generation/`](word-search-generation) |
| Square Packing++ | [`square-packing/`](square-packing) |
| Masyu | [`masyu/`](masyu) |
| Black box | [`black-box/`](black-box) |
| Bonus: Document Lego | [`document-lego/`](document-lego) |

Requires Python 3.13+. No third-party dependencies.
